Getting Snowflake Access

  1. If you already have Snowflake access, skip this step.
  2. To get access to Snowflake, ensure that you have completed the following UF training:
    • UF_PRV800: HIPAA Awareness Training
    • UF_PRV802: FERPA Training
    • UF_PRV804: Protecting Social Security Numbers & Identity Theft Prevention
  3. Lastinger associates can request the roles through HR by submitting the HR Request Form.
  4. Lastinger associates will need to request the UF_N_SNFLK_ALL_USERS role in MyUFL and the UF_N_SNFLK_LASTINGER_DE_USER_AUTOGS role in Snowflake. Make sure to include both roles in your request to HR.

Logging into Snowflake

  1. If you are currently logged into Snowflake, skip this step.
  2. Otherwise, log into Snowflake from this link. this link. By clicking Single Sign-On, you will go through Duo Mobile’s familiar authentication process with Microsoft and the University of Florida.

Workspace Access and Setup

  1. Any database queries will happen on an SQL file. You can use one you have previously created; or you can create a new SQL file via the Add New button in the window’s upper-left corner.
  2. In the upper-right corner of the coding environment, press (warehouse icon) to confirm that you are using the REPORTING warehouse. Press (database icon) to select PUB_LAKE_LASTINGER as your database, and then the following for your schema:
    • FINAL for tables of datasets standardized by the Data Management team: enrollments, surveys, etc.
    • LAKE_LASTINGER for tables directly from the MySQL database: Brightspace, Salesforce, etc.

SQL Querying

  1. You can begin querying in the coding environment. Here are some examples of inputs:

    Querying all Elementary Micro-Credentials enrollments:

    SELECT * FROM FINAL.ENROLLMENTS_ELEMENTARY_MICRO

    A query for Brightspace users:

    SELECT * FROM LAKE_LASTINGER.brightspace_users

    Prepending the table name with its schema is only required if that table is outside of your current schema.

  2. To download your results, press the (download icon) icon and select your desired format.
  3. To review Snowflake’s SQL documentation, follow this link.
